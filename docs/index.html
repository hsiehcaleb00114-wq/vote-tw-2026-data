選舉通

2026 九合一地方選舉 App：投票倒數、我的選票、參選人查詢、開票結果與歷屆選舉資料。

本 App 為民間製作，非中央選舉委員會或任何政府機關的官方 App，與任何政黨、候選人無關。資料整理自中央選舉委員會公開資料，如有出入以中選會公告為準。

問題回報與建議

發現資料錯誤、App 有問題，或有功能建議，請到 GitHub 問題回報 留言。

常見問題

資料多久更新一次？
App 開啟時會自動下載最新資料，不用更新 App。開票當天約每 5 分鐘更新一次。

投票提醒沒有跳出來？
請到手機「設定」確認選舉通的通知權限已開啟。

我的戶籍地資料會上傳嗎？
不會，只存在你的手機裡。詳見隱私權政策。
